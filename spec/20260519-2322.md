# 一个 aliyun ecs 实例监控器

## 背景

我购买的 aliyun ecs 抢占式实例会由于单价波动被临时停机, 我希望监控实例状态并检测到被停机以后自动启动实例

## 配置

- 配置文件 yaml 格式
- 用户认证配置: AccessKeyId=xxx, AccessKeySecret=yyy
- 可配置多个 aliyun ecs 实例: RegionID=cn-hangzhou, InstancesID=i-bp1f7c1zqp999zvp****
- 可选配电报机器人通知: BotToken=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ, ChatID=-100123456789
- 轮询间隔: 默认 60s

## 实现细节

- 使用 golang 编写
- 配置 .github/workflows 在收到 push tag 事件或手动输入 tag 触发时自动构建 docker 镜像并发布到 github 镜像仓库
- aliyun ecs sdk 使用 github.com/alibabacloud-go/ecs-20160314
- 查询实例状态文档地址: https://api.aliyun.com/document/Ecs/2014-05-26/DescribeInstanceStatus
- 启动实例文档地址: https://api.aliyun.com/document/Ecs/2014-05-26/StartInstance
